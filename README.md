# Smart Campus Information System

## About the Project
Smart Campus Information System is a Python-based web application designed to organize and manage campus-related information. It provides a structured approach to handling student information and student performance data through a web interface.

## Features
- Web-based application built using Python and Flask.
- Database-related functionality for managing application data.
- Student performance data handling using CSV.
- Organized HTML templates and static assets.
- Modular project structure for easier maintenance.

## Tech Stack
- **Programming Language:** Python
- **Framework:** Flask
- **Data File:** CSV

## Project Structure
- `app.py` – Main application
- `database.py` – Database-related operations
- `database/` – Database files or related resources
- `static/` – Static assets
- `templates/` – HTML templates
- `student_performance.csv` – Student performance dataset
- `requirements.txt` – Python dependencies

## How to Run
1. Clone or download this repository.
2. Install Python if it is not already installed.
3. Install the required dependencies:

   pip install -r requirements.txt

4. Run the application:

   python app.py
   

5. Open the local URL displayed in the terminal.

## Learning Outcomes
This project provided practical exposure to Python web development, application structure, database integration, and handling structured student data.
